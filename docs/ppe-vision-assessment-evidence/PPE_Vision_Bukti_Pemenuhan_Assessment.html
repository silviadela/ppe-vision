Apakah “Tambah Eksperimen” diwajibkan?

Tidak diwajibkan. Tidak ada kalimat pada ketentuan yang meminta CRUD eksperimen, tombol membuat eksperimen, atau pencatatan banyak run. Yang diminta adalah web menampilkan setting training, hasil training/matriks, dan demo model.

Bagaimana data final diperbarui?

Data model final berasal dari hasil training/evaluasi, metadata checkpoint, dan seeder. Production memakai ALLOW_ADMIN_WRITES=false karena belum ada login admin. UI online bersifat read-only dan pengunjung tidak dapat membuat record baru atau mengubah hasil final.

Keputusan final untuk assessment: tampilkan model final secara read-only. Menu Eksperimen tetap menjadi halaman bukti setting dan artefak, sedangkan tombol membuat eksperimen sudah dihapus agar alurnya tidak ambigu.

Syarat 1

Object Detection YOLO + Python untuk PPE

Terpenuhi Sistem benar-benar memuat checkpoint YOLO di Python dan menjalankan inferensi bounding box; bukan sekadar menampilkan gambar hasil statis.

Apa yang diminta?

Aplikasi harus mendeteksi objek PPE menggunakan keluarga YOLO dan implementasi Python.

Implementasi

  • inference_service/models/best.pt adalah checkpoint final YOLO26s.
  • streamlit_app/app.py memuat checkpoint melalui ultralytics.YOLO.
  • Fungsi predict_frame() memanggil model.predict().
  • Input didukung: gambar, video, dan kamera.
  • inference_service/main.py menyediakan alternatif API FastAPI lokal.
model = YOLO(model_path) result = model.predict( source=frame, conf=confidence, imgsz=image_size, )[0]

Jawaban saat ditanya

“Saya menggunakan Ultralytics YOLO26s pada Python. Checkpoint final best.pt dimuat oleh Streamlit/FastAPI, lalu model.predict menghasilkan kelas, confidence, dan bounding box untuk gambar, video, atau kamera.”

Cara membuktikan langsung

  1. Buka Demo Deteksi.
  2. Pilih tab gambar/kamera.
  3. Masukkan input yang memuat PPE.
  4. Tunjukkan kotak, kelas, confidence, dan ringkasan jumlah deteksi.
  5. Jika cold start, tunggu status “Model siap”.

Mengapa test dan validation dipisah?

Kurva sepanjang epoch berasal dari validation karena digunakan untuk memantau proses dan memilih checkpoint. Nilai headline berasal dari 212 gambar test independen untuk menilai model final secara lebih objektif.

Point plus 2

AI lokal menggunakan Ollama

Terpenuhi Ollama 0.40.4 menjalankan llama3.2:3b pada komputer lokal melalui 127.0.0.1:11434.

OLLAMA_ENABLED=true OLLAMA_URL=http://127.0.0.1:11434 OLLAMA_MODEL=llama3.2:3b

Alur integrasi

  1. Laravel mengambil metrik dari TrainingRun.
  2. Service membuat prompt terstruktur.
  3. HTTP POST dikirim ke /api/generate.
  4. Ollama mengembalikan JSON risiko dan tiga rekomendasi.
  5. Laravel memvalidasi, menyusun Markdown, dan menyimpan ke MySQL.
  6. Production menampilkan hasil tersimpan tanpa membuka Ollama ke internet.

Mengapa bukan live dari InfinityFree?

127.0.0.1 pada InfinityFree berarti server InfinityFree sendiri, bukan laptop pengguna. Paket gratis juga tidak menjalankan Ollama. Karena itu narasi dibuat secara lokal lalu disimpan. Ini tetap memenuhi penggunaan AI lokal sekaligus menjaga model lokal tidak diekspos tanpa autentikasi.

Jawaban saat ditanya

“Ollama sengaja tetap lokal. Saya menjalankan summary di laptop, memvalidasi output, lalu menyimpan hasilnya agar portal online stabil. Server gratis tidak dapat mengakses localhost laptop.”

Jawaban assessor

Pertanyaan yang kemungkinan muncul

Q: Apakah semua ketentuan sudah terpenuhi?Ya. Lima syarat inti dan tiga point plus memiliki implementasi serta bukti. Batasannya adalah admin production sengaja read-only dan Ollama berjalan lokal, bukan live di InfinityFree.
Q: Di mana bukti YOLO dan Python?Ultralytics YOLO dimuat pada streamlit_app/app.py dan inference_service/main.py; checkpoint ada di inference_service/models/best.pt.
Q: Mengapa tidak ada tombol Eksperimen Baru?Tombol tersebut bukan bagian syarat dan hanya membuat record, bukan menjalankan training. Bukti setting/hasil sudah tersedia pada halaman detail read-only.
Q: Mengapa tidak training dari Laravel?Training YOLO membutuhkan Python/GPU/proses panjang. Laravel dipakai sebagai portal; Colab dipakai untuk training.
Q: Mengapa Ollama tidak online?Syarat meminta AI lokal. Ollama berjalan lokal dan hasil disimpan; InfinityFree tidak dapat mengakses localhost laptop.
Q: Apakah summary bisa dipercaya?Angka tidak dibuat LLM. Angka berasal dari database/model metadata; LLM hanya memberi risiko dan rekomendasi dengan schema serta fallback.
Q: Mengapa model kadang tidak mendeteksi tiga kelas sekaligus?Metrik bersifat agregat. Satu frame hanya menghasilkan kelas yang terlihat, cukup besar, teranotasi konsisten, dan melewati confidence threshold.
Q: Kelas terlemah?Masker, mAP50-95 63,4% dan recall 87,5%. Dataset perlu lebih banyak variasi objek kecil, sudut, occlusion, dan cahaya.
Q: Apa alasan memilih model ini?Dari lima trial random search, trial 4 memiliki skor gabungan terbaik, lalu konfigurasi tersebut dilatih 60 epoch pada data train penuh dan dievaluasi pada test independen.
