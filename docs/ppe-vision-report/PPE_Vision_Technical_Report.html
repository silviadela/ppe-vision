Mengapa menggunakan random search?

Hyperparameter seperti learning rate, momentum, dan weight decay memengaruhi cara model belajar. Lima trial pendek dijalankan selama 20 epoch pada 60% data. Trial 4 memiliki skor gabungan tertinggi pada catatan eksperimen, sehingga konfigurasinya dipakai untuk final training 60 epoch pada seluruh data train.

Pemisahan data yang benar

Definisi sederhana

MetrikRumus / maknaCara membaca hasil proyek
PrecisionTP / (TP + FP). Dari semua deteksi yang dibuat, berapa yang benar?95,5% menunjukkan false positive relatif rendah.
RecallTP / (TP + FN). Dari semua objek yang seharusnya ditemukan, berapa yang berhasil ditemukan?90,7% baik, tetapi masih ada risiko objek terlewat (false negative).
F12 × P × R / (P + R). Keseimbangan precision dan recall.93,0% menunjukkan keseimbangan kuat.
IoULuas irisan bounding box dibagi luas gabungan.Mengukur ketepatan posisi kotak prediksi terhadap label.
APLuas di bawah precision–recall curve untuk satu kelas.Meringkas performa kelas pada berbagai threshold.
mAP50Rata-rata AP pada IoU 0,50.95,7%; objek umumnya ditemukan dan kotaknya cukup bertumpuk.
mAP50-95Rata-rata AP pada IoU 0,50 sampai 0,95.69,3%; lebih ketat karena menilai ketepatan lokasi kotak pada banyak IoU.
Mengapa mAP50 tinggi tetapi mAP50-95 lebih rendah? mAP50 cukup puas jika kotak overlap 50%. mAP50-95 juga menguji overlap sangat ketat sampai 95%. Selisih ini berarti klasifikasi objek sudah kuat, tetapi posisi/ukuran bounding box masih dapat diperbaiki.

Alur inferensi YOLO: dari input sampai bounding box

1
Input
Pengguna memilih gambar, video, atau foto kamera di Streamlit.
2
Validasi
Format, ukuran, dan nilai confidence diperiksa. FastAPI membatasi gambar 10 MB; Streamlit membatasi pilihan format UI.
3
Load model
best.pt dimuat satu kali melalui cache agar request berikutnya lebih cepat.
4
Predict
Ultralytics menjalankan model.predict(..., conf=threshold, imgsz=image_size).
5
Normalisasi kelas
Helmet → helm, Mask → masker, Person → people.
6
Output
Sistem menggambar bounding box, label, confidence, membuat tabel, menghitung jumlah kelas, dan mencatat waktu inferensi.
CLASS_ALIASES = {
    "helmet": "helm",
    "mask": "masker",
    "person": "people",
}

result = model.predict(
    source=frame,
    conf=confidence,
    imgsz=image_size,
    verbose=False,
)[0]

Mengapa tiga kelas tidak selalu tampil sekaligus?

Model memiliki tiga kelas, tetapi output hanya berisi kelas yang benar-benar terdeteksi pada input dan melewati confidence threshold. Jika gambar hanya berisi orang dan helm, keluaran Masker bisa nol. Nilai nol bukan berarti kelas hilang dari model.

Confidence threshold

  • Threshold rendah: lebih banyak objek ditemukan, tetapi false positive dapat meningkat.
  • Threshold tinggi: prediksi lebih selektif, tetapi false negative dapat meningkat.
  • Default proyek 0,20 dipilih agar objek PPE kecil tidak mudah terlewat; tetap perlu diuji pada kondisi lapangan.

Bab 9

Ollama: alasan, integrasi, dan kontrol halusinasi

Mengapa Ollama?

  • Lokal dan privat: data metrik tidak perlu dikirim ke API pihak ketiga.
  • Tanpa API key/biaya per request: sesuai assessment dan keterbatasan biaya.
  • Model ringan: Llama 3.2 3B berukuran sekitar 2 GB dan dapat berjalan pada CPU.
  • Fallback tersedia: bila Ollama mati atau timeout, sistem tetap menghasilkan ringkasan berbasis aturan.

Alur generasi

1
Laravel mengambil metrik dan per-class metrics dari TrainingRun.
2
Service menghitung kelas terlemah sendiri, bukan meminta LLM menebak.
3
Prompt mengirim data terstruktur, tetapi melarang LLM menulis angka/persentase.
4
Ollama harus mengembalikan JSON berisi operational_risk dan tepat tiga recommendations.
5
Laravel memvalidasi JSON, fokus kelas terlemah, kata “confusion” dan “confidence”. Jika gagal, fallback rule-based dipakai.
6
Angka kesimpulan dan per kelas disusun ulang langsung dari database, lalu Markdown disimpan.
$response = Http::connectTimeout(5)->timeout(180)->post(
    rtrim(config('services.ollama.url'), '/') . '/api/generate',
    [
        'model' => config('services.ollama.model'),
        'stream' => false,
        'prompt' => $this->prompt($run),
        'format' => $this->responseSchema(),
        'options' => ['temperature' => 0.2, 'num_predict' => 360],
    ]
);

Mengapa temperature 0,2?

Temperature rendah membuat output lebih konsisten dan tidak terlalu kreatif. Untuk analisis metrik, konsistensi lebih penting daripada variasi bahasa.

Bagaimana mencegah angka AI tidak sama dengan dashboard?

LLM tidak diberi tanggung jawab mencetak angka. Metode structuredSummary() mengambil precision, recall, F1, mAP50, mAP50-95, dan per-class mAP langsung dari database. Karena dashboard membaca record yang sama, keduanya konsisten.

Jawaban wawancara terbaik: “Saya tidak menjadikan LLM sebagai sumber kebenaran numerik. Database adalah source of truth. LLM hanya membantu menyusun risiko operasional dan rekomendasi, lalu jawabannya divalidasi dan memiliki fallback deterministik.”

Bab 10

Database dan hubungan data

training_runs1 eksperimen/model
1 → N
detectionsRiwayat inferensi

Tabel training_runs

Menyimpan identitas model, konfigurasi training, status, timestamps, JSON metrik, metrik per kelas, confusion matrix, history per epoch, path artefak, AI summary, engine pembuat summary, dan catatan eksperimen.

Tabel detections

Menyimpan file sumber, output annotated image, array deteksi, waktu inferensi, mode, status, dan pesan error. Foreign key ke training run bersifat nullable dan menggunakan nullOnDelete(), sehingga riwayat tidak menyebabkan kegagalan jika eksperimen dihapus.

Mengapa kolom metrik memakai JSON?

Jumlah dan bentuk metrik eksperimen dapat berkembang. JSON memudahkan menyimpan nested validation, dataset split, dan artefak tanpa menambah kolom untuk setiap variasi. Identitas dan field yang sering difilter tetap memakai kolom biasa.

Seeder sebagai jembatan local → production

DatabaseSeeder mengisi satu record model final, membaca training history dari CSV, mencatat path artefak, serta menanam AI summary yang telah dibuat lokal. Di InfinityFree, seeder dijalankan melalui halaman installer karena tidak ada SSH.

Idempotensi praktis: seeder mencari record melalui path checkpoint atau nama model lama, lalu memperbaruinya. Ini mencegah model final terus diduplikasi saat deployment diperbarui.

Bab 12

Deployment online dan alasan pemisahannya

Laravel di InfinityFree

InfinityFree menyediakan PHP, MySQL, SSL, subdomain, dan FTP gratis, tetapi tidak menyediakan SSH, Composer, atau NPM. Karena itu seluruh dependency dan asset dibangun lebih dahulu di komputer.

1
build-package.ps1 menyalin source Laravel yang dibutuhkan.
2
composer install --no-dev --optimize-autoloader membuat vendor production.
3
npm ci dan npm run build membuat public/build; node_modules lalu dibuang.
4
APP_KEY unik dibuat dan direktori writable disiapkan.
5
Paket awal dan paket update-safe dibuat. Update-safe tidak membawa .env.
6
Isi htdocs diunggah melalui FileZilla.
7
Installer bertoken menjalankan migration + seeder; token lalu dikosongkan agar route kembali 404.

Mengapa root .htaccess diperlukan?

Document root InfinityFree adalah htdocs, sedangkan entry point Laravel berada di public/index.php. Root .htaccess menulis ulang request ke public/, melarang file tersembunyi seperti .env, dan menambahkan security headers.

Streamlit Community Cloud

Streamlit menarik repository GitHub, memasang streamlit_app/requirements.txt serta system package dari packages.txt, lalu menjalankan streamlit_app/app.py. Checkpoint dapat dibundel atau diunduh dari HTTPS dan selalu diverifikasi SHA-256.

Kenapa aplikasi Streamlit kadang “waking up”?

Paket gratis menidurkan aplikasi yang tidak aktif. Ketika dibuka lagi, container, dependency, dan model perlu dimuat. Cold start 1–3 menit bukan error model. Buka link Streamlit langsung, tunggu sampai “Model siap”, lalu kembali ke Laravel.

Bab 18

Naskah presentasi 5–7 menit

1. Masalah (30 detik)PPE Vision membantu mengevaluasi dan mendemokan object detection untuk tiga kelas keselamatan: Helm, Masker, dan People. Targetnya bukan hanya model, tetapi juga sistem yang dapat dipahami dan diakses online.
2. Model dan data (60 detik)Saya menggunakan checkpoint YOLO26s final. Data dibagi menjadi 3.025 train, 603 validation, dan 212 test independen. Lima random-search trial digunakan untuk memilih hyperparameter, kemudian konfigurasi terbaik dilatih 60 epoch.
3. Hasil (60 detik)Pada test independen, precision 95,5%, recall 90,7%, F1 93,0%, mAP50 95,7%, dan mAP50-95 69,3%. Kelas terlemah adalah Masker dengan mAP50-95 63,4%, sehingga perbaikan berikutnya fokus pada anotasi dan variasi masker.
4. Arsitektur (75 detik)Laravel 12 menjadi portal utama dan MySQL menyimpan eksperimen. Streamlit menjalankan Python/YOLO di cloud karena InfinityFree hanya mendukung PHP. Demo Streamlit ditanam ke Laravel melalui iframe. Untuk pengembangan lokal tersedia FastAPI.
5. AI Summary (60 detik)Ollama llama3.2:3b berjalan lokal. Untuk mencegah halusinasi, LLM tidak mencetak angka; angka selalu diambil dari database. LLM hanya memberi risiko dan tiga rekomendasi dalam JSON schema, kemudian Laravel memvalidasi dan menyediakan fallback rule-based.
6. Keamanan dan deploy (60 detik)Secret tidak masuk Git, installer bertoken dikunci setelah dipakai, operasi admin dimatikan di production, upload divalidasi, model diverifikasi SHA-256, dan update-safe tidak membawa `.env`.
7. Penutup (30 detik)Seluruh syarat inti dan point plus terpenuhi. Pengembangan selanjutnya adalah memperbaiki dataset kelas Masker, menambah data lapangan, menguji threshold, dan mengukur performa pada perangkat target.
Bab 19

Pertanyaan wawancara yang mungkin muncul

Q: Mengapa memakai Laravel dan Streamlit sekaligus?Laravel mengelola UI utama, route, database, validasi, keamanan, dan riwayat eksperimen. Streamlit menjalankan runtime Python/PyTorch yang tidak tersedia di InfinityFree. Pengguna tetap melihat satu portal karena Streamlit di-embed.
Q: Mengapa tidak semuanya dibuat dengan Streamlit?Syarat point plus meminta Laravel UI/UX. Selain itu Laravel lebih terstruktur untuk CRUD, database, middleware, CSRF, migration, dan halaman laporan.
Q: Mengapa Ollama tidak berjalan langsung di hosting?Ollama memerlukan proses runtime dan resource model sekitar 2 GB. InfinityFree tidak mendukung proses tersebut. Assessment meminta AI lokal, sehingga Ollama dijalankan lokal dan hasilnya disimpan untuk ditampilkan online.
Q: Bagaimana memastikan AI Summary tidak mengarang angka?LLM dilarang menulis angka. Laravel menghitung dan mencetak angka dari database. Respons LLM memakai JSON schema, divalidasi, dan memiliki fallback deterministik.
Q: Mengapa memakai Llama 3.2 3B?Lebih ringan daripada model besar, cukup untuk merangkum metrik dalam Bahasa Indonesia, berjalan lokal tanpa API key, dan latency masih masuk akal pada CPU.
Q: Apa perbedaan validation dan test?Validation dipantau selama training untuk memilih model. Test independen dipakai setelah keputusan model selesai agar estimasi generalisasi lebih jujur.
Q: Mengapa mAP50-95 dipakai sebagai metrik utama?Ia menilai kualitas deteksi pada berbagai IoU, sehingga lebih ketat dan representatif daripada hanya mAP50.
Q: Mengapa Masker paling lemah?Masker berukuran kecil, variasinya besar, mudah tertutup/menyatu dengan wajah, dan kualitas anotasi semuka dapat membuat bounding box tidak konsisten.
Q: Apakah model bisa mendeteksi tiga kelas sekaligus?Bisa, jika ketiganya ada, terlihat cukup jelas, dan melewati threshold. Model memiliki tiga class head; keluaran per gambar tetap tergantung konten.
Q: Mengapa confidence default 0,20?Untuk mengurangi objek PPE kecil yang terlewat. Nilai ini trade-off dan harus diuji lagi pada kondisi deployment sebenarnya.
Q: Apa fungsi FastAPI bila sudah ada Streamlit?FastAPI adalah jalur integrasi lokal Laravel → Python yang menyimpan riwayat deteksi ke DB. Streamlit adalah demo mandiri untuk hosting online dan video/kamera.
Q: Bagaimana model dijaga integritasnya?Metadata menyimpan SHA-256. Streamlit menghitung checksum sebelum memuat model; file yang tidak cocok ditolak.
Q: Bagaimana upload diamankan?MIME/ekstensi dibatasi, ukuran dibatasi, image didecode, pixel maksimum ditetapkan, dan threshold divalidasi.
Q: Mengapa installer lewat web?InfinityFree gratis tidak memberi SSH. Installer bertoken menjadi jembatan menjalankan migration dan seeder; setelah selesai token dikosongkan sehingga route 404.
Q: Bagaimana update tanpa merusak konfigurasi?Upload isi update-safe/htdocs; paket ini sengaja tidak memiliki `.env`, sehingga APP_KEY dan kredensial MySQL server tidak tertimpa.
Q: Mengapa Streamlit lambat saat pertama dibuka?Free tier menidurkan aplikasi. Container perlu bangun dan model perlu dimuat. Request berikutnya lebih cepat karena resource cache.
Q: Apa kekurangan sistem saat ini?Masker masih kelas terlemah, demo gratis memiliki cold start, inferensi video memakai CPU, belum ada tracking identitas unik antar-frame, dan evaluasi lapangan perlu diperluas.
Q: Apa pengembangan selanjutnya?Audit anotasi Masker, tambah hard examples, lakukan class balancing/augmentation terkontrol, threshold calibration, tracking video, monitoring latency, dan uji pada data lokasi target.
Q: Apakah angka dashboard dan summary benar-benar sama?Ya. Feature test membandingkan seed database terhadap model-info.json hingga toleransi 1e-9 dan menguji angka yang dirender di dashboard.
Q: Apa yang terjadi bila Ollama gagal?Exception dicatat, kemudian sistem memakai summary lokal berbasis aturan. Halaman tetap berfungsi dan engine ditandai bukan LLM.
