Jawaban paling penting

InfinityFree bukan API, dan Ollama memang hybrid

InfinityFree itu apa?

InfinityFree adalah hosting untuk menjalankan Laravel/PHP dan MySQL. Laravel tidak “mengambil API InfinityFree”. Browser mengirim request HTTPS ke Laravel yang kebetulan berjalan di server InfinityFree.

Ollama itu apa?

Ollama adalah runtime model bahasa lokal. Laravel lokal memanggil HTTP API Ollama di 127.0.0.1:11434/api/generate.

Apakah Ollama dipakai 100%?

Tidak untuk seluruh isi halaman, dan itu disengaja. Angka, persentase, F1, daftar metrik per kelas, serta kelas terlemah dihitung oleh Laravel dari database. Ollama menghasilkan bagian kualitatif: risiko operasional dan tiga rekomendasi. Laravel kemudian memvalidasi dan menyatukan keduanya.

Apakah memenuhi assessment? Ya. Ketentuan point plus meminta AI lokal untuk merangkum hasil metrik menggunakan Ollama/llama.cpp. Ollama benar-benar dipanggil dan menyusun bagian analisis. Ketentuan tidak meminta LLM menghitung ulang angka atau menjadi satu-satunya komponen.
Yang harus didemonstrasikan: jalankan Laravel dan Ollama secara lokal, klik “Buat ulang dengan Ollama”, lalu tunjukkan label Analisis oleh Ollama · llama3.2:3b. Halaman online menampilkan hasil yang sudah disimpan; ia tidak memanggil laptop secara live.

Kenapa browser yang menghubungi Streamlit?

Iframe bekerja client-side. InfinityFree hanya mengirim alamat iframe dalam HTML. Ini menghindari kebutuhan PHP server untuk meneruskan video dan menjalankan Python.

Cold start: bila Streamlit tidur, browser melihat “waking up”. Setelah container, dependency, dan model dimuat, demo kembali siap tanpa deploy ulang.

Bab 7

Mengapa tidak 100% diserahkan kepada Ollama?

1. Angka tidak boleh dihalusinasikan

LLM dirancang menghasilkan bahasa, bukan menjadi kalkulator sumber kebenaran. Bila prompt berisi 69,299%, model dapat membulatkan, menukar angka, atau menulis metrik yang tidak tersedia. Laravel dapat memformat nilai database secara pasti.

2. Kelas terlemah dapat dihitung deterministik

Mengurutkan tiga nilai mAP adalah operasi sederhana. Menyerahkannya kepada LLM menambah ketidakpastian tanpa manfaat.

3. Halaman harus tetap tersedia

Model lokal pertama kali dimuat bisa lambat, Ollama bisa belum dijalankan, atau request dapat timeout. Fallback membuat pengguna tetap memperoleh ringkasan dasar dan label engine secara jujur.

4. AI tetap benar-benar digunakan

Ollama menyusun risiko dan rekomendasi—bagian yang memerlukan bahasa serta pertimbangan kualitatif. Laravel bukan mengganti hasil Ollama secara total; Laravel menjaga batas agar output relevan dan aman.

DesainKelebihanRisiko
100% LLMTerlihat “lebih AI”.Angka bisa salah, format berubah, gagal jika model mati.
Hybrid sekarangAngka akurat, AI memberi insight, fallback tersedia.Perlu menjelaskan pembagian tanggung jawab.
100% rule-basedStabil dan cepat.Tidak membuktikan penggunaan Ollama.
Kesimpulan assessment: hybrid adalah penggunaan Ollama yang valid dan secara engineering lebih baik. Yang penting, saat engine berhasil, metadata harus tertulis “Ollama · llama3.2:3b”; saat fallback, aplikasi harus jujur menulis “Analisis lokal berbasis aturan (bukan LLM)”.
Jika assessor meminta “harus sepenuhnya Ollama”: jangan biarkan LLM membuat angka. Jelaskan bahwa seluruh narasi kualitatif dibuat Ollama, sementara angka dikunci dari hasil evaluasi. Ini adalah kontrol integritas, bukan pengurangan AI.

Mengapa 127.0.0.1 berbeda?

Laravel lokal

127.0.0.1 menunjuk laptop yang sama. Laravel dapat menjangkau Ollama dan FastAPI.

Laravel InfinityFree

127.0.0.1 menunjuk server InfinityFree. Ia tidak pernah berarti laptop Anda.

Jangan membuka Ollama mentah ke internet. API lokal umumnya tidak memiliki autentikasi aplikasi. Jika suatu hari dibuat remote, letakkan di belakang HTTPS, auth, firewall, rate limit, dan logging.

Bab 15

Tanya-jawab integrasi

Q: Laravel ambil API dari InfinityFree?Tidak. Laravel berjalan di InfinityFree. Ia membaca MySQL menggunakan koneksi database dan mengirim HTML ke browser.
Q: Siapa yang memanggil Streamlit?Browser pengguna melalui iframe. Server Laravel hanya menyisipkan URL Streamlit.
Q: Apakah Laravel online memanggil Ollama laptop?Tidak. Alamat localhost pada server berbeda dari localhost laptop. Production membaca summary tersimpan.
Q: Kalau begitu apakah Ollama benar-benar dipakai?Ya, saat generate lokal Laravel mengirim request ke API Ollama. Hasil disimpan bersama nama engine. Automated test juga memverifikasi bentuk request dan output.
Q: Mengapa ada fallback?Agar aplikasi tidak gagal ketika model lokal belum aktif atau timeout. Label engine jujur membedakan fallback dari LLM.
Q: Mengapa tidak semua kalimat berasal dari Ollama?Angka dan peringkat kelas adalah fakta yang harus deterministik. Ollama difokuskan pada risiko dan rekomendasi, tempat kemampuan bahasa memberi nilai.
Q: Apakah assessment mewajibkan 100% LLM?Tidak. Teks meminta AI lokal untuk summarization menggunakan Ollama/llama.cpp. Desain hybrid tetap memakai Ollama untuk summary sambil mengunci fakta numerik.
Q: FastAPI dipakai online?Tidak pada deployment final. Ia adalah jalur integrasi lokal alternatif dan bukti Laravel dapat berkomunikasi dengan service Python melalui REST.
Q: Mengapa dua jalur inference?Streamlit cocok untuk demo hosted gratis; FastAPI cocok untuk arsitektur service-to-service ketika Python server tersedia.

Checklist pemahaman

  • □ Dapat menjelaskan InfinityFree adalah hosting, bukan API.
  • □ Dapat menggambar jalur browser → Laravel → MySQL.
  • □ Dapat menggambar jalur browser → Streamlit → YOLO.
  • □ Dapat menjelaskan FastAPI hanya alternatif lokal.
  • □ Dapat menjelaskan Laravel → Ollama lokal → DB.
  • □ Dapat menjelaskan mengapa summary online tidak live ke Ollama.
  • □ Dapat mempertahankan alasan desain hybrid.
